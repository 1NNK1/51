# 🛒 MyStore - Курсовой проект (ДЗ 51.1)

Проект представляет собой интернет-магазин электроники, разработанный для демонстрации навыков работы с React, Redux Toolkit и специализированными библиотеками.

##  Функционал
- **Каталог товаров**: Динамическая загрузка товаров с имитацией API.
- **Корзина**: Полноценное управление заказами (добавление, удаление, изменение количества).
- **Интеграция библиотек**:
  - `react-icons`: Иконки для интерфейса (корзина, магазин, удаление).
  - `react-toastify`: Интерактивные уведомления о действиях пользователя.
  - `react-idle-timer`: Система отслеживания бездействия пользователя для повышения безопасности и UX.

##  Установка и запуск
1. Клонируйте репозиторий или распакуйте архив.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите проект в режиме разработки:
   ```bash
   npm run dev
   ```

##  Используемые технологии
- React 18
- Redux Toolkit
- Vite
- React Icons
- React Toastify
- React Idle Timer
